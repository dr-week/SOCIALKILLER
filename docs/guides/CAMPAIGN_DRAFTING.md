# Campaign Drafting Guide

## Purpose

Document the content-drafting workflow used by The Social Base. Generated content is a draft for an operator to review.

## Inputs

- Brand/workspace voice and audience
- Campaign goal and platform
- Verified facts, links, and source material
- Optional format such as short video, announcement, or discussion prompt

## Draft structure

1. State a specific, verifiable hook.
2. Explain the context or problem in plain language.
3. Share the actual work, evidence, or lesson.
4. End with a relevant question or next step when appropriate.

Never invent personal experiences, metrics, endorsements, or news. Research outputs must retain source links; verify facts before publishing. Avoid repetitive cross-posting and tailor each draft to the destination community's rules.

## Review and delivery

Edit each platform variant, confirm links/media and destination, then submit through a supported API or the platform's composer. The operator owns the final submission. The Lua preview feature does not publish content.
